# Support

## Before asking for help

Please check that:

- Docker / Docker Compose is running.
- Jellyfin is reachable from the Personal Cable TV server.
- Your Jellyfin API key is valid.
- Your media volume points to the correct host folder and remains read-only.
- Port 8484 is available unless you intentionally changed the published host port.
- M3U and XMLTV URLs from Personal Cable TV have been added to Jellyfin Live TV.

## Report a problem

Open a GitHub Issue and include:

- Personal Cable TV version
- Installation method (CasaOS, Docker Compose, or other)
- Jellyfin version
- What you expected to happen
- What actually happened
- Relevant error text or screenshots

Do **not** post passwords, API keys, access tokens, private credentials, or copyrighted media files.
